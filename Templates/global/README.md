# Global knowledge template

Use this scope for durable information that applies across projects: stable preferences, general methods, recurring constraints, and cross-project lessons.

Do not place one project's status here merely because its project scope has not been identified.

On first-use setup, reuse any existing user-profile authority. If this scope is
still only this template, the model may add the user's introduction, preferences,
and short onboarding progress here after the user begins setup. Keep actual
answers local; do not populate example personal information during installation.
