# 支持范围与维护路线

当前候选版本为 `0.1.0-preview.1`，采用 PolyForm Noncommercial 1.0.0。功能可试用，尚未承诺稳定 API、固定响应时限或所有客户端的相同行为。

## 首发范围

- 桌面使用、本地 Markdown 知识目录、自然语言知识操作和离线 HTML 视图。
- Codex 是当前原生验收主线；其余四个客户端保留适配器，但按实验适配发布。
- 本地回归以 macOS 为已执行环境。CI 定义 Linux / macOS、Python 3.9 / 3.13 检查矩阵；只有对应运行成功后才视为该组合通过。
- Windows 与手机不在本轮已验证范围。不同模型和客户端版本需要单独验证，不能由安装成功推导。

## 接下来按证据推进

| 阶段 | 目标 | 完成依据 |
| --- | --- | --- |
| 首个预览版 | 干净历史、自动检查、版本包、主力客户端流程、排障入口 | 当前源码的测试、原生流程报告、远端 CI 和 Release 可对应到同一提交 |
| 用户试用 | 发现安装和持续使用障碍 | 收集使用虚构复现数据的反馈；验证用户能自行完成记录、查找和回顾 |
| 扩展兼容 | 逐个升级实验客户端的支持等级 | 同一虚构用例、实际客户端版本与文件差异证据，而非只新增适配文件 |
| 稳定版 | 明确迁移、恢复和兼容承诺 | 连续预览版升级验证和真实使用反馈支持该承诺 |

## 暂不承诺

移动端、云同步、团队协作、后台自动监听、托管模型服务和自动心理画像。需要这些能力时先提出具体场景，不在现有安装器中隐式加入服务。

## 维护与贡献

维护者根据可复现性、影响范围与数据安全排序处理问题；预览阶段没有商业 SLA。Issue 用于缺陷和功能建议，Pull Request 用于可审阅的修改。对商业授权有需求，可提出不含私人资料的授权咨询；当前仓库不提供自动购买或授予商业许可。

当前接受按本项目非商业许可证提交的贡献，不自动获得贡献者的商业再许可权。若未来考虑包含外部贡献的商业版本，将先逐项取得必要权利；详见 [贡献指南](../CONTRIBUTING.md)。
