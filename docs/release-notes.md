# HanOS 0.1.0-preview.3

源码公开预览版，采用 PolyForm Noncommercial 1.0.0。允许许可证规定范围内的非商业使用；商业用途需要单独授权。

## 本次更新

知识星图固定为 `midnight-atlas@1.0.0`。所有 Agent 和模型调用同一份生成器，颜色、版式、布局算法、搜索、阅读器及缩放交互由程序确定；禁止自行仿写页面或在失败后交付替代设计。

- `template-lock.json` 固定生成器与布局模块的 SHA-256；缺失或变更时拒绝生成，保护已有输出。
- 新增 `--check-template` 检查安装资产；安装和发布打包也会执行检查。
- 新增只读 `--verify-output`，重新读取注册笔记并逐字节核对完整 HTML。生成后自动复核，通过后才报告 `HANOS_HTML_VERIFY=PASS`。
- 页面被改写、被宿主注入属性，或源笔记发生变化时均需重新生成；保留标题或模板标记不足以冒充标准产物。
- 布局执行直接使用已验证的源码字节，防止历史 Python 缓存与锁定源码不一致。

## 验证范围

五种客户端隔离安装均携带相同模板，针对同一来源生成完整 HTML，除生成时间外完全一致；覆盖模板变更、缺失文件、产物改写、来源更新、旧缓存和安装/导出拒绝路径。目标提交的完整回归、Linux Python 3.9/3.13、macOS Python 3.13 及 Git 历史密钥扫描结果见 GitHub Actions。

这是分发、安装与生成器证据，不等于逐一完成所有 Agent/模型的原生会话验收。原生支持范围继续以 docs/portability-report.md 为准。

## 安装和升级

下载完整 ZIP 并解压，在包含 install.py 的目录运行 `python3 install.py --agent codex`，或选择其他已有适配器。需要 Python 3.9 或以上；知识目录必须在源码之外。不要只下载 SKILL.md，也不要让模型照截图重建页面。

升级沿用原知识目录和显示名称。重新加载 Skill 或开启新会话，然后重新生成 HTML；旧 HTML 不会自动升级，也无法通过新版标准产物校验。已有笔记不会迁移或改写。

交付前可独立校验：

```bash
python3 skills/hanos/scripts/generate_html.py --config "/path/to/config.json" --verify-output "/path/to/knowledge-overview.html"
```

若宿主预览会回写 HTML，保留 `.hanos` 内的原始产物，交付并校验原文件；被修改的预览不能算标准结果。

## 已知限制

当前面向桌面和个人知识使用，仍为预览版。Codex 是原生验收主线，其余适配器尚未完成等价原生验证。当前支持证据以 docs/portability-report.md 为准；跨操作系统 CI 的实际运行状态以目标提交的检查记录为准。

笔记数量、关系和系统字体会影响图谱的具体呈现，但不能由模型更换模板。SHA-256 校验用于发现相对于随包锁文件的漂移，不是数字签名，也不防止整个校验器与锁被一并替换。

真实知识生成的 HTML 包含正文和路径，应保密。README 包含虚构演示的真实页面截图、8 秒操作动图与 MP4；顶部概念插图另有明确标注。原始原生评测日志不随包发布。没有后台服务、同步或手机支持承诺，也没有自动卸载命令；手动停用和保留知识的卸载步骤见 docs/troubleshooting.md。
