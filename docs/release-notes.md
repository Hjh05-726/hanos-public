# HanOS 0.1.0-preview.2

源码公开预览版，采用 PolyForm Noncommercial 1.0.0。允许许可证规定范围内的非商业使用；商业用途需要单独授权。

## 本次更新

- “开启我的知识库”只准备当前对话中的知识工作流；查看图谱时打开 HTML，只有明确要求时才打开 Obsidian。
- 首次引导说明“我是你的知识库助手，你可以给我取一个名字，以后有需要喊我就行。你想叫我什么？”
- 搜索覆盖正文、子标题和标签，显示匹配数量或无结果提示；结果可点击阅读，星图同步突出匹配笔记。
- 记录、整理和召回保留用户原话与助手建议的区别，来源不明的旧记录保持待核实。

## 验证范围

功能提交已通过 Linux Python 3.9/3.13、macOS Python 3.13 的每组 90 项检查及 Git 历史密钥扫描，HTML 修复已获用户手动验收。来源保留通过两个隔离 Codex 会话的整理、召回样本复验。发布提交的自动检查见 GitHub Actions；其他客户端仍未完成等价原生验收。

## 安装和升级

解压版本包，在包含 install.py 的目录运行 `python3 install.py --agent codex`，或选择其他实验适配器。Python 3.9 或以上；知识目录必须在源码之外。升级沿用原知识目录和显示名称，重新加载客户端，然后请求重新生成 HTML，旧 HTML 不会自动更新。已有笔记不自动迁移或改写；历史确认状态有疑问时需回查原始依据。

## 已知限制

当前面向桌面和个人知识使用，仍为预览版。Codex 是原生验收主线，其余适配器尚未完成等价原生验证。当前支持证据以 docs/portability-report.md 为准；跨操作系统 CI 的实际运行状态以目标提交的检查记录为准。

真实知识生成的 HTML 包含正文和路径，应保密。README 包含虚构演示的真实页面截图、8 秒操作动图与 MP4；顶部概念插图另有明确标注。原始原生评测日志不随包发布。没有后台服务、同步或手机支持承诺，也没有自动卸载命令；手动停用和保留知识的卸载步骤见 docs/troubleshooting.md。
