# HanOS 0.1.0-preview.1

源码公开预览版，采用 PolyForm Noncommercial 1.0.0。允许许可证规定范围内的非商业使用；商业用途需要单独授权。

## 这个版本提供什么

- 一个共享 Skill 核心，支持明确调用与适合长期保留内容的谨慎沉淀。
- 对话式首次引导、Markdown 知识整理和检索、日记反馈。
- 桌面离线星图：横向布局、细粒度缩放、关联高亮和同页阅读。
- 五种客户端适配器、标准库安装器、自检、升级漂移检测。
- 精确发布清单、版本化构建和 CI 工作流。

## 安装和升级

解压版本包，在包含 install.py 的目录运行 `python3 install.py --agent codex`，或选择其他实验适配器。Python 3.9 或以上；知识目录必须在源码之外。升级沿用原知识目录和显示名称，然后重新生成 HTML。

## 已知限制

当前面向桌面和个人知识使用，仍为预览版。Codex 是原生验收主线，其余适配器尚未完成等价原生验证。当前支持证据以 docs/portability-report.md 为准；跨操作系统 CI 的实际运行状态以目标提交的检查记录为准。

真实知识生成的 HTML 包含正文和路径，应保密。README 概念图不是产品截图。原始原生评测日志不随包发布。没有后台服务、同步或手机支持承诺，也没有自动卸载命令；手动停用和保留知识的卸载步骤见 docs/troubleshooting.md。
